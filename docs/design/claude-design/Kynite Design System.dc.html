Event categories

A category carries two things: a colour and an icon. Eleven categories share eight colours, so three colours carry two categories each — the icon is what separates them. The component takes a colour, an icon and a label; which category maps to which pair is a product decision.

Where the icon shows
  • List rows, cards, the all-day band, the day board and the category picker: colour bar, icon, title, avatar.
  • Time-grid blocks: icon at 14px with a 15px avatar; below roughly 40px height the block keeps only the coloured fill and bar.
  • Private "busy" blocks have no category, so they carry a lock instead of an icon — the avatar still shows whose agenda it is.

Calendar view patterns

Building blocks for day, week and month across the two contexts. On the hub, day splits into a column per family member. On mobile, week becomes an agenda list and month becomes a dot grid with the selected day below it — a 7-column time grid is unreadable at 390px.

Weer

Weer staat op de Vandaag-pagina als samenvatting van nu, met een doorklik naar zeven dagen. Elk weertype heeft een eigen hue: de gevulde Material Symbol staat in oklch(50% c h) op een tegel in oklch(94% c h) van dezelfde hue. Dagtypes met zon blijven warm, neerslag en nacht koel. Bij elk type hoort één rustige lus-animatie, die uitvalt bij prefers-reduced-motion.

Weer-widget · kaartthema per weertype

De hele kaart draagt het weer: een verloop als lucht, en rechts een bewegende laag — draaiende zonnestralen, overdrijvende wolken, vallende druppels, een korte bliksem. De tekst blijft links op een rustig deel van het verloop staan. Alles stopt bij prefers-reduced-motion.

Feestdagen & vakanties

Op de betreffende datum vervangt een thema-banner tijdelijk het "Nu"-blok bovenaan Vandaag. Het icoon-tegeltje volgt de opbouw van het merkicoon (gelaagde kleurcirkels), opgebouwd uit bestaande Kynite-kleuren, met een silhouet dat bij het thema past (boom, mijter, pompoen, kroon). Automatisch actief op basis van de kalenderdatum. Staat de dag nog voor de deur, dan krijgt de banner rechts een aftelteller (witte kaart, indigo cijfer); op de dag zelf vervalt de teller.
