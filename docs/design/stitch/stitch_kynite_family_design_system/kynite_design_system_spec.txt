# Kynite Design System Overview

## Brand Voice
"Routines without the friction." Warm, organized, playful yet functional.

## Component Specifications
- **Primary Button**: Indigo-600 background, white text, rounded-xl, 48px height.
- **Secondary Button**: Amber-500 for celebratory actions, soft-rounded.
- **Event Card**: Tinted category background (e.g., soft blue), colored left border (solid blue), rounded corners.
- **Now Card**: Accent-tinted (Primary color), subtle glow or elevation.
- **Avatar**: Pill-shaped with a category-colored ring.
- **Streak Indicator**: Flame/Star icon with the secondary amber accent.
- **Typography**: 
  - Display L: 48px / 1.1 leading (Wall-hub greeting)
  - Display M: 36px (Glanceable time)
  - Heading: 24px (Section titles)
  - Body: 16px
  - UI Labels: 14px Medium
  - Tabular Numbers: Mono/Tabular for 00:00 time formats.

## Accessibility
- Touch targets: 48x48px minimum.
- Contrast: WCAG AA compliant.
- Distance: Legible from 2 meters for Wall Hub views.
